# 05 — Tooltips, Actions & Comments

Tooltips · Actions and Comments

---

## Tooltips

**Don't forget to edit the tooltips.** Try to make them as logical and clear as possible,
**without unnecessary repetition** and in a **single style** across the whole dashboard:

- Use the **same color and font** for tooltips as for the main text.
  The preferred base font size is **10px**.
- **Group text into paragraphs**, highlight key elements in **bold**, and use **parameters**
  (where necessary) to make the tooltips clearer.

> 💡 A reminder that you can **embed some charts** into tooltips (viz in tooltip).

### Quality-tooltip checklist

- [ ] Same font/color as the main text (Tableau Book, target **10px**).
- [ ] Text split into paragraphs, key parts in **bold**.
- [ ] No duplication of what is already visible on the chart.
- [ ] A single style across all visualizations on the dashboard.
- [ ] Where appropriate — parameters and/or a mini-chart.

---

## Actions and Comments

**Action filters** make the dashboard more interactive and allow quick filtering.
Don't forget to **describe the navigation** so that the action filters are as "transparent" and
understandable as possible.

- To **describe action filters**, use the font: **Tableau Book, 9pt, `#666666`**.

### Dashboard / procedure descriptions

- If you need to add a **dashboard description** or describe a procedure, its specifics and
  operating principles — we recommend placing this information in the **popup window under the
  "Info" icon (ⓘ)**.
- When a description must be added **directly on the dashboard**, use the font:
  **Tableau Book, 9pt, `#666666`**.

---

## Summary of fonts for text explanations

| Text purpose | Font |
|--------------|------|
| Main text / tooltip | Tableau Book, **10px**, `#333333` |
| Action-filter description | Tableau Book, **9pt**, `#666666` |
| Comment/description directly on the dashboard | Tableau Book, **9pt**, `#666666` |
| Text under the ⓘ icon (in the popover) | Tableau Book, **10px**, `#333333` |

> Color logic: `#333333` is primary content; `#666666` is supporting explanations, navigation, comments.
