Скіл для Claude Code

Виправляє .twbx за стайлгайдом Upstars —
і доводить, що він відкриється в Tableau.

twbx-lint — скіл для Claude Code. Він приводить Tableau-дашборди у відповідність до стайлгайду Upstars — типографіку, кольори, макет, поведінку фільтрів — і перевіряє результат, реально відкривши його в Tableau Desktop, а не лише проглянувши XML. Оригінал у dummy/ лишається байт-у-байт незмінним.

dummy/не змінено

Останні рядки справжнього звіту скіла — без обох PASS і OK він не вважає роботу завершеною.

Встановлення

/plugin marketplace add lizabrovko-creator/claudius-public
/plugin install upstars@claudius

Якщо Claude Code напише «Run /reload-plugins to activate.» — виконай /reload-plugins.

Працює лише на macOS — детальніше в розділі «Вимоги» нижче.

Щоденне використання

/upstars:twbx-lint dummy/my-dashboard.twbx

Поклади файл у dummy/ і виклич команду. Без аргументу скіл візьме найновіший .twbx із dummy/.

Що виправлено; вердикт щодо кожного з цих чотирьох розділів; що лишилось невиправленим і чому; рядок валідації; рядок відкриття в Tableau; і що саме треба підтвердити очима у відкритому вікні.

Вимоги

macOS — обов'язково. open-verify шукає Tableau Desktop у /Applications; на Windows і Linux команда повертає SKIP, а SKIP — це не успіх, тож довести роботу до кінця там неможливо.

  • Tableau Desktop — без нього немає фінальної перевірки відкриття.
  • Python 3.10+ — скрипт використовує сучасні анотації типів.
  • xmllint — на macOS є з коробки; на Linux це пакунок libxml2-utils.

Три рівні перевірок

1 Структура claude plugin validate --strict ~0.3 с · автоматично
2 Логіка pytest ~2 с · автоматично
3 Поведінка моделі LLM-евали години, платно · лише вручну

Тести не запускаються під час звичайної роботи. Вони спрацьовують лише коли змінюються вихідники самого скіла.
